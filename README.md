## 🧩 Blockbench plugins

A small toolkit for color, textures, palettes, animation and viewport presentation.
Every plugin is **bilingual — English / Russian**.

### 🎨 Color & palettes

- **Palette Swap** — recolor a whole family of shades at once, keeping the shading
- **Recolor by Hue** — hue / saturation / lightness / contrast with a live model preview
- **Posterize / Quantize** — reduce colors to steps or to a palette
- **Dither Ramp** — dithered two-color gradient texture
- **Palette Extractor** — pull the main colors out of a texture
- **Shadow / Light Auto** — automatic shadows & highlights from one base color
- **2-Color / 3-Color Ramp** — smooth hue-shifted color ramps

### 🎬 Animation

- **Focus Keyframes** — show only the tracks that actually have keyframes
- **Clean Animation Speed** — change speed without fractional frames
- **Animation Retime** — reverse & phase-shift animations (whole or selected keyframes)
- **Onion Skin** — ghost frames to check motion arcs

### 🖼️ Viewport

- **Viewport Studio** — light, effects & shaders baked into renders

### 🧩 Плагины для Blockbench

Небольшой набор инструментов для работы с цветом, текстурами, палитрами, анимацией и подачей модели.
Все плагины **двуязычные — русский / английский**.

**🎨 Цвет и палитры**

- **Palette Swap** — меняет целое семейство оттенков разом, сохраняя затенение
- **Recolor by Hue** — оттенок / насыщенность / яркость / контраст с живым превью на модели
- **Posterize / Quantize** — сведение к N ступеням цвета или к палитре
- **Dither Ramp** — дизеринг-переход между двумя цветами
- **Palette Extractor** — извлечение основных цветов текстуры
- **Shadow / Light Auto** — авто-тени и блики из одного базового цвета
- **2-Color / 3-Color Ramp** — плавные рампы со сдвигом тона

**🎬 Анимация**

- **Focus Keyframes** — показывает только дорожки с ключевыми кадрами
- **Clean Animation Speed** — смена скорости без дробных кадров
- **Animation Retime** — разворот и сдвиг фазы (вся анимация или выделенное)
- **Onion Skin** — «призраки» соседних кадров для выверки движения

**🖼️ Вьюпорт**

- **Viewport Studio** — свет, эффекты и шейдеры, бейкаются в рендер
